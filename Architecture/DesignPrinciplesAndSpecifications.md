## 4. 轻量级架构

### 4.1 DRY（Don`t Repeat Yourself）

减少重复

- 代码复用
- 工具类
- 长Code是魔鬼
- 重构+设计模式

### 4.2 KISS（Keep it simple and stupid）

- 无感知
- 接入成本
- 0/极少配置
- Clean Code
- 方法尽量可以用一句话描述

### 4.3 YAGNI（You Ain`t Gonna Need It）

过度设计

- 分布式事务
- 数据异构
- 规则引擎
- GraphQL

**Try everything you can to keep it simple**
